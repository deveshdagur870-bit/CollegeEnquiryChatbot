# College Enquiry Chatbot

A chatbot that answers college enquiries such as admissions, courses and fees.

## Tech Stack
- Backend: Java (Maven)
- Database: SQLite
- Frontend: HTML, CSS, JavaScript

## Project Structure
- `src/main/java/com/collegebot/` - Java source code
- `src/main/resources/web/` - Chat UI (HTML, CSS, JS)
- `src/main/resources/db/schema.sql` - Database schema

## How to Run
1. Clone the repository
2. Open it in IntelliJ IDEA
3. Run `mvn clean install`
4. Run `Main.java`
